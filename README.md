# Legal Surface Copy - Sophisticated Gradient UI

A refined, sophisticated version of the legal surface website with rich gradients, glassmorphism, and smooth animations.

## Features
- Elegant gradient color scheme (purple to blue primary, orange gradient for buttons)
- Glassmorphism effect on the main container
- Animated background with moving gradients
- Sparkle effects (disabled on mobile for performance)
- Smooth hover animations on button
- Responsive design
- Custom fonts (Playfair Display for headings, Inter for body)
- Dynamic year in footer

## Files
- `index.html` - Main HTML structure
- `style.css` - All styling including gradients, animations, and responsive design

## How to Use
1. Copy the entire `legal-surface-copy` folder to your web server
2. Ensure both `index.html` and `style.css` are in the same directory
3. Open `index.html` in any modern browser

## Customization
- To change the primary gradient, edit `--primary-gradient` in `:root` in style.css
- To change the secondary gradient (button), edit `--secondary-gradient`
- Adjust animation speeds by modifying the `animation` properties
- Change fonts by updating the Google Fonts links in index.html and font-family in style.css
